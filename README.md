# Delegado de guardia (borrador)

Juego de capacitación para delegadas y delegados: cómo acompañar a un compañero que está preocupado por otra persona con señales de riesgo suicida. Un solo `index.html`, sin dependencias; se abre con doble clic.

**Estado: borrador para revisión de profesionales de salud mental y del Centro de Asistencia al Suicida. No publicar antes de esa revisión.**

## Cómo está armado

- Chat con Rubén; el jugador es el delegado y elige qué contestar.
- Cada tramo ofrece cuatro respuestas: tres estereotipos torpes (El Fiestero, El Coach Ontológico, El NoPasaNada) y una que sirve. El estereotipo se revela después de elegir.
- Las torpes tienen reacción graciosa de Rubén y una nota «Por qué no»; se coleccionan en el álbum (15 frases).
- Tramo 3: mecánica de recortar un mensaje largo hasta dejar la pregunta directa.
- Todo el contenido está en `BEATS` dentro del `<script>`. El botón rojo AYUDA está siempre visible.

## Criterios de seguridad aplicados

- El jugador nunca es la persona en riesgo ni se muestra métodos, lugares ni desenlaces.
- El humor apunta a las torpezas de quien acompaña, no a quien sufre.
- Sin tiempo límite ni puntaje que presione; ninguna pantalla termina mal.
- Cierre estilo «efecto Papageno» (se acompaña y se sigue presente).
